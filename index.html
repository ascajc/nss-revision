Your five traps

From today's wrong answers

  1. Trap 1 · CIA wording

    Disclosure is a loss of confidentiality, not integrity. Integrity = modification or destruction.

  2. Trap 2 · FIPS 199 names

    Only Low, Moderate, High are levels. "Limited" and "Serious" are adjectives inside the definitions.

  3. Trap 3 · Defence emphasis

    Passive attacks → prevent. Detect and recover is for active attacks.

  4. Trap 4 · Publishers

    RFC → IETF, always. X.800 → ITU-T. FIPS 199 → NIST.

  5. Trap 5 · Threat vs attack

    "Derives from an intelligent threat" is the attack definition. A threat is only the potential.

Ask what the attacker did

They saw it → C. They changed or deleted it → I. They blocked it → A.
Lecturer's example: a hacker changes your blood type at the GP → C and I.

Limited, Serious, Severe. Two S words, two different levels, and only the second one kills.

Slides 30–32

Passive vs active attacks

"Once you start changing things, you start to be an active attacker."

Passive: learn, don't touch

  • Release of message contents: reading the email, call or file
  • Traffic analysis: contents encrypted, but who, how often and how long are still visible

Very hard to detect, because nothing changes.

Defence: PREVENT (encryption)

Active: alter or disrupt

  • Masquerade: pretend to be someone else
  • Replay: capture a valid message, resend it later
  • Modification: alter, delay or reorder messages
  • Denial of service: stop normal use

Too hard to prevent outright.

Defence: DETECT + RECOVER
Lecturer's DNS example

Listening to DNS queries = passive. Changing the returned IP to send the victim to a fake site = active.

Lecturer, transcript 1:33

"X.800, it gives the architecture level of cybersecurity. The RFC gives the vocabulary of cybersecurity."

X.800's three core concepts

AttackAny action that compromises an organisation's information security
→
ServiceCounters attacks. What you get, e.g. confidentiality
→
MechanismDetects, prevents or recovers. How you get it, e.g. encryption

Encryption is a mechanism, so it is never one of the X.800 services.

RFC 4949: threat vs attack

Threat

A potential for violation: a circumstance or capability that could cause harm.

Attack

An actual assault that derives from an intelligent threat: a deliberate attempt to evade security.

"Threat is the potential, attack is the action."

Week 2 preview · L02 slides 14–19

DNS: the internet's phone book

You type www.google.com, but computers route by IP address. The Domain Name System turns the name into the number.

  1. DHCP gives the laptop its IP, the first-hop router and the DNS server's address

  2. ARP finds the router's MAC address

  3. DNS: the query goes in UDP → IP → Ethernet to the DNS server, which replies with Google's IP

  4. TCP handshake: SYN → SYNACK → ACK

  5. HTTP request for the page

Passive risk

Plain DNS isn't encrypted, so an eavesdropper sees every site you look up.

Active risk

Spoofing or poisoning the reply sends you to a fake site.

Defences such as DNSSEC and DNS over HTTPS are background knowledge, not taught yet.
