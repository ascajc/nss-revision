Privacy policy

Effective 13/10/2026.

Personal Workspace Tool is a private tool used only by its owner, with the owner's own Google account.

What data it accesses

Only the Google account data the owner approves on the Google sign-in screen.

How the data is used

The data is used only to show and manage the owner's own information on the owner's own computer. It is not sold, shared with anyone, or used for advertising.

Storage

Sign-in tokens are stored encrypted on the owner's computer. No data is kept on any server run by this tool.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
